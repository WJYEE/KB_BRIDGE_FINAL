# 전처리 노트북 안내

이 폴더는 제공받은 작업 노트북을 보존한 목록입니다. 파일명 순서가 실행 순서는 아닙니다.

- `인허가 파생지표.ipynb`: 월별 인허가 파생지표 생성 작업.
- `인허가최종처리.ipynb`, `인허가 마무리.ipynb`, `인허가_ram안터지는방법.ipynb`: 후속 처리·월별 파일 결합 작업. 적용 순서와 최종 채택본은 담당자 확인 필요.
- `인허가_작업용처리.ipynb`, `인허가_컬럼처리.ipynb`, `인허가_전처리.ipynb`, `인허가수집확인.ipynb`: 중간 처리·확인 기록.
- `원본CSV_병합점검.ipynb`: 원래 Untitled1.ipynb. 여러 CSV를 이어 붙여 점검하는 코드이며 전체 원천 최종 통합 코드는 아님.
- 카드·통신 컬럼 수정 노트북: 이름 정리 작업이며 주요 파생변수 생성 전체 코드는 아님.

실제 입력 데이터가 없어 전체 재실행은 하지 않았습니다. 경로는 원래 코드의 경로를 유지했습니다.

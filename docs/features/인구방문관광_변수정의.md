# 담당 세 자료 통합 EDA 전달 안내

## 통합 데이터
- 파일: 01_인구방문관광_통합.csv
- 크기: 7,790행 × 20열
- 한 행: 행정동 한 곳 × 예측기준월 한 달
- 연결 키: 예측기준월 + 행정동코드
- 카드·통신·부동산·점포·폐업 정답은 포함하지 않았다.
- 최종 점포 학습표에는 위 키로 LEFT JOIN하고 행 수·중복을 재검수한다.
- 지역 코드와 예측기준월은 문자열로 읽는다.

## 지역·시간 기준
- 거주인구는 행정동 단위다.
- 방문자·관광은 구군 단위다.
  같은 구군의 여러 행정동에 동일 값이 반복된다.
  행정동별로 새로 측정하거나 배분한 값이 아니다.
- 모든 변수는 전월 관측자료를 사용한다.
- 예: 202602 예측에는 202601 관측자료 사용.
- 실제 공개 지연·과거 개정은 미반영인 소급평가다.

## 모델 후보 지표 8개
- resident_yoy
- 외지인_일평균, 외국인_일평균
- 외지인_전월대비_변화율, 외국인_전월대비_변화율
- 외지인_직전3개월평균대비_변화율
- 외국인_직전3개월평균대비_변화율
- 관광체류강도

## 정의·단위
- resident_yoy = 전월 거주인구 / 전년도 같은 관측월 거주인구 - 1
- 전월 변화율 = 관측월 일평균 / 직전월 일평균 - 1
- 3개월평균 대비 = 관측월 일평균 / 직전 3개월 일평균 값의 평균 - 1
- 3개월 평균에 현재 관측월은 포함하지 않는다.
- 변화율 0.1은 10%이며 100%를 초과할 수 있다.
- 방문자 수는 월별 일평균이지 월 전체 고유 방문자 수가 아니다.
- 관광체류강도는 코드21의 지수이며 백분율·인원 수가 아니다.
- 원인구·관측월·코드·상태는 추적 보조정보다.
  모든 열을 자동으로 모델 입력에 넣지 않는다.

## 결측
- 202301 방문자·관광 지표는 202212 자료 부재로 각 205행 결측이다.
- 빈칸은 0이 아니므로 임의로 채우거나 행을 삭제하지 않았다.
- 거주인구 변화율은 모든 행에 값이 있다.

## EDA 해석
- 주 CSV는 행정동·월 표다.
- 기존 학습용 EDA 4,049,217행은 점포·월 표로 집계 단위가 다르다.
- 기존 기초통계·상관·구별 비교는 점포·월 기준이다.
- 3개자료_통합표_* 검수는 이번 행정동·월 통합표 기준이다.
- 같은 점포·지역 값의 반복을 독립 관측으로 해석하지 않는다.
- 라벨 관련 분석은 학습 구간에서 수행했다.
- 학습 기준월 202301~202508, 시험 기준월 202602로 분석했다.
  최종 사용 전 팀 학습 명세와 맞춘다.
- 고상관 변수 두 쌍은 표시했으며 자동 삭제하지 않았다.
- 폐업 날짜 집중 원인은 미확인이다.
- 신호동 인구는 녹산동에 포함됐다는 담당자 확인을 적용했다.
- 업종별 탐색 비교는 노트북에 실행 결과가 있다.
  전체 업종별 CSV 저장 여부: True
- 최근 인허가 업종 기준의 탐색 비교는 최종 대표업종 정책과 별도다.
- 다른 담당자의 카드·통신 등 지표 EDA는 이번 범위에 포함하지 않는다.

## 3. 채울 때 규칙

- 값은 **원문 사이트에서 직접 본 것**만 쓴다. 뉴스·블로그는 참고만 하고 인용하지 않는다.
- 발행일을 못 찾으면 "확인 못 함"이라고 적는다. 추정해서 쓰지 않는다.
- 채운 뒤 보안_기준_및_점검.md (`../보안_기준_및_점검.md` — 별도 참조 파일, 이 묶음에는 미포함) 2절 표의 "확인" 열을 "확인 완료(날짜)"로 바꾼다.
- 3번의 발행 주체가 금융위원회인지 금융보안원인지 검색 결과가 엇갈렸다. 원문에서 확인한다.

# 현재 상태와 남은 파일

정리 기준: 2026-10-30. 받은 자료의 문서·코드 정리본이며 모델링·배포 완료본이 아닙니다.

## 확보한 코드
- 기존 공공데이터 수집 모듈·수집 노트북.
- 인허가 전처리, 파생변수 생성, 월별 파일 처리, EDA 노트북. 최신 실행 순서는 담당자 확인 필요.
- 카드·통신 컬럼 정리, 카드 지표 EDA, 통신 4개 지표 재계산 검산, 카드·통신 병합 EDA 노트북 확보. 카드 주요 지표 생성·저장과 통신 원본 정제·생성물 최종 저장은 미확보.
- 인구·방문·관광 통합 EDA 노트북과 과거 검수 결과.
- 부동산 v04~v07 연결·요약 코드. v05가 import하는 select_published_quarter.py는 이 묶음에 없어 해당 단계 단독 실행 불가.
- 2026-10-30 전체 설명변수 Pearson 상관분석 결과. 해당 결과를 생성한 최종 노트북은 별도로 추가할 것.

## 추가할 파일
1. 카드 원본 전처리·주요 파생변수 생성·저장 코드 및 카드_파생지표_결과.md 등 정의 문서(현재 EDA는 v05 입력).
2. 통신 원본 정제·최종 v03 저장 코드와 정의 문서. 확보한 EDA에는 4개 지표 재계산·대조 코드가 있음.
3. 모든 원천자료를 합쳐 최종 ver2 Parquet를 저장한 통합 코드.
4. 인구·방문·관광을 2026-07 예측기준월까지 확장한 최종 생성 코드(별도 노트북이면 추가).
5. 부동산 기본 정제·공표시점 선택 코드 및 실행에 필요한 나머지 단계.
6. 모델 학습·평가 코드, 최종 채택 변수·시간분할 설정, 모델 성능표.
7. Streamlit 앱과 화면 자원, 실제 실행환경 버전.

## 문서와 구현의 차이
- PRD v0.2는 제공 원문을 보존했다. 부동산 모델 제외·관광 확보 검토·주민등록인구 미정 등의 옛 상태가 남아 있다.
- 실제 모델링 입력에 부동산·인구·방문·관광이 포함된 현황과 PRD를 추후 일치시킬 것.
- 체크리스트의 예시 날짜나 완료 표시를 확정된 최신 실행 설정으로 해석하지 않는다.
- 상관분석 결과의 학습 범위는 2023-01~2025-02이다. 전체 실험의 최신 시간분할은 모델 담당자가 확정·기록해야 한다.
- 보안 출처목록 원본에는 금융 안내서 발행주체·날짜 등 확인 전/파일명 기준 문구가 남아 있다. 공식 근거 확인표와 구분한다.
- SHAP·모델 성능·대시보드 기능은 제공 코드가 확인되기 전까지 구현 완료로 표시하지 않는다.

## 공개 업로드 처리
- 실제 인증키를 환경변수 조회로 변경했고 노트북의 실행 출력·실행 번호·위젯 상태를 제거했다.
- 원본과 점포별 정제·보존·제외 목록, 대용량 통합 데이터는 묶음에 넣지 않았다.
- 노트북 실행 출력 초기화로 그래프는 실행 후 생성된다. 별도 제공 EDA 요약 PDF는 reports/eda에 보존했다.
- GitHub에 이미 커밋된 키나 비밀정보가 있다면 이 ZIP 업로드만으로 과거 이력이 지워지지는 않는다.

## 카드·통신 추가 노트북 검토
- 01_카드_파생지표_EDA: 카드데이터_전처리_v05.csv를 읽어 지표 5개 등을 분석. 해당 5개 지표를 처음 생성·저장하는 전체 코드는 아님.
- 02_통신_파생지표_EDA: v02·v03을 읽어 시간대·월별 EDA와 4개 지표 재계산 검산. 재계산 코드는 포함되지만 원자료 정제·v03 생성 전체를 재현하는 저장 단계는 아님.
- 03_카드통신_합치기_EDA: 기준월+행정동코드로 m:1 left merge하고 카드통신_통합데이터_v01.csv 저장. 인허가·부동산·인구방문관광까지 합친 최종 모델용 병합이 아님.
- 코드의 상한은 202602인데 설명에는 202603 등 옛 수치가 남음. 수치를 단순 치환하지 않고 재실행 전까지 참고 기록으로 보존.
- 카드 라벨 분석은 202407~202508로 현재 Pearson 학습 범위와 다름. 최종 모델 선택용 분석으로 바로 쓰지 않음.

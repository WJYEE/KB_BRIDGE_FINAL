# 07. 전처리 규칙 한눈에 보기

어떤 열을 남기고, 지우고, 바꿨는지를 카테고리별로 모았다. 열 하나하나의 채움률과 결정 ID는 06_컬럼_추적표.md (`06_컬럼_추적표.md` — 별도 참조 파일, 이 묶음에는 미포함), 이유는 04_컬럼_결정기록.md (`04_컬럼_결정기록.md` — 별도 참조 파일, 이 묶음에는 미포함).
삭제한 열은 값이 사라지는 것이 아니라 정제본에서만 빠지고 processed/archive 파일에 남는다.

## 공통 처리 순서

1. 업종별 CSV(cp949)를 합침: 열은 파일에서 처음 나온 순서의 합집합, 그 업종 파일에 없는 열은 빈 값. 파일명에서 `업종명` 열을 만들어 첫 열에 둠.
2. (영업상태가 '폐업' 또는 폐업일자가 있음) 이고 폐업일자 < 2023-01-01 인 행은 정제본에서 빼서 processed/excluded에 보관.
3. 아래 표의 삭제 열을 정제본에서 제거.
4. 좌표정보(X)·(Y)는 앞뒤 공백을 제거하고 숫자(float)로 변환. 나머지 값은 바꾸지 않음.

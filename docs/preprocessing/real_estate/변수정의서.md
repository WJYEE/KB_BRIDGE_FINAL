# 변수정의서 — `부동산_행정동별_월별_연결자료.csv`

1,632행 × 26열, UTF-8 BOM. 한 행 = 행정동 × 기준월. 키는 (`행정동코드_카드10자리`, `기준월`)이며 중복이 없다(SGIS 코드 기준으로도 중복 없음).

## 성격
모든 지표는 **조사상권 기반 대리변수**다. 한국부동산원 상업용부동산 임대동향조사의 **조사상권별 값**을, 상권 경계와 행정동 경계가 겹치는 면적으로 행정동에 연결한 값이다. **공식 행정동 통계가 아니며 행정동 전체의 실제 공실률·임대료를 뜻하지 않는다.** 공실률은 상권 표본의 공실면적 비율, 임대료는 상가 1층 기준 거래가능 월세환산임대료(공식 정의)다.

## 지표 산식
1. 상권 면적 대비 겹침이 1% 미만인 상권–행정동 연결은 먼저 제외한다.
2. 남은 연결 중 해당 상가유형·지표에 사용 분기 값이 있는 상권(유효 상권)만 쓴다.
3. 유효 상권이 1개면 그 상권 값, 2개 이상이면 겹침면적 가중평균:
   `값 = Σ(겹침면적_k × 상권값_k) ÷ Σ 겹침면적_k` (겹침면적 = 상권 k와 해당 행정동이 겹치는 면적, ㎡)

## 커버율
- `공간커버율_유형무관(0~1)`: 1% 미만 제외 후 남은 연결 상권들이 행정동 면적에서 차지하는 비율(합집합 면적 ÷ 행정동 면적).
- `{지표}__유효값커버율(0~1)`: 그 지표 값 계산에 실제로 쓰인 상권들이 행정동 면적에서 차지하는 비율. 값이 행정동의 얼마만큼을 대표하는지 보여 준다. 최소 기준은 두지 않았다(낮은 값도 남아 있음).

# 처리기준서 — 부동산(임대료·공실률) 전처리

각 항목을 **[적용]** 현재 적용한 기준과 **[가정·미확정]** 아직 확정되지 않은 가정으로 구분한다.

## 1. 원본 기본 정제
- [적용] 한국부동산원 상업용부동산 임대동향조사 부산 CSV 25개(공실률·임대료, 소규모·집합·일반·일반 1층). 3줄 헤더를 분리하고 분기 열을 세로로 바꿨다. 2,797칸 전부 보존했고 값 변경은 0이다. 원문 값과 원본 행·열을 기록했다.
- [적용] 부산전체 행과 조사상권을 구분했다. 상가유형·지표는 합치지 않았다. 상권명은 원문 그대로 두었다(서면·서면전포·서면/전포 등을 통합하지 않음).
- [적용] 부산전체 값은 공식 보도자료와 대조했다(71개 일치).

## 2. 상권 → 행정동 연결
- [적용] 상권 경계 SHP(`상권구획도2024`, 368개)를 EPSG:5179로 바꾸고, 무효 도형 보정 후 SGIS 행정동 경계(2025-06-30, 206개)와 면적 중첩했다. 부산 상권 27개를 공간 기준으로 식별했고 조사 표 상권명과 정확 일치로 대응했다.
- [적용] SGIS 8자리 코드와 카드 10자리 코드는 구군+행정동명 정확 일치로 대응했다(205/206, 신호동 미대응).
- [가정·미확정] 상권 SHP의 입수 경로·제작 주체는 미확인이며 공식 경계로 확정하지 않았다. 10자리 코드 대응은 이름 기준 잠정 대응이다.

## 3. 1% 미만 겹침 제외 → 가중평균
- [적용] 상권 면적 대비 겹침이 1% 미만인 연결 24개를 **먼저 제외**했다(100개 중 76개 유지). 지도 검토에서 대부분 경계를 따라 닿은 얇은 띠였다. 제외한 면적은 다른 동으로 옮기지 않았다.
- [적용] 남은 연결에서 유효 상권이 1개면 그 값, 2개 이상이면 겹침면적 가중평균을 썼다. 최소 커버율 기준은 두지 않았다.
- [가정·미확정] **1%는 공식 기준이 아닌 실험 기준**이다. 개별 예외 후보 4건(부곡4동, 부암1동, 대연5동, 부전2동)은 미적용이며 팀 판단이 필요하다.

## 4. 공표일을 고려한 분기 → 기준월 연결
- [적용] 기준월에는 그 시점에 이미 공표된 최신 분기만 연결한다. 공표일은 한국부동산원 보도자료 게시판 등록일(2022Q1~2026Q2)이다. 분기 값을 3등분·보간하거나 월별 관측값으로 만들지 않았다.
- [적용] 일반 상가·1층 공실률은 최초 공표(2026-04-30) 이전 기준월에는 쓰지 않는다. 그래서 2026-05부터만 값이 있다.
- [적용] 2024Q3 이전 분기는 경계 연결을 보류했다. 그래서 2024-10 이전 기준월은 값이 없다.
- [가정·미확정] 기준월 컷오프는 **월말, 공표 당일 미사용**을 시험 가정으로 쓴다. 2024Q3 경계를 이후에도 고정 적용한다는 가정이다(이후 변경 여부 미확인).

## 5. 0과 결측의 구분
- [적용] 원본 0은 그대로 둔다(상권 표본 내 공실면적 0). 결측은 빈칸이며 0이나 평균으로 채우지 않는다.
- [적용] 빈칸 사유는 ① **원본 자료 없음**(겹치는 조사상권 없음, 상권에 해당 유형 자료 없음), ② **과거 경계 연결 보류**(원본 값은 있으나 2024Q3 이전), ③ **공표 전**(그 기준월에 공표된 분기 없음)으로 나뉜다. 빈칸이 모두 원자료가 없는 것은 아니다.
- [적용] 6개 지표가 모두 빈 행 7,844행은 주 사용 CSV에서 빼서 사유와 함께 관리표에 보관했다(경계 보류+공표 전 4,532행, 원본 자료 없음+공표 전 2,484행, 원본 자료 없음 828행). 일부 지표만 빈 행은 유지했다.

## 6. 보류 항목과 미확인 사항
- [보류] `2626년 2분기` 원문(일반 상가 1층, 원본 22건)은 2026Q2 오기로 보이나 원표를 확인하지 못해 연결하지 않았다.
- [보류] 서면·서면전포·중구시장 등 과거 상권명은 2024 경계가 없어 연결하지 않았다.
- [미확인] 상권 SHP 출처, 공식 경계와의 대조, 일반 상가 2026Q2 원본 파일, R-ONE 데이터 게시 시각과 사후 개정 여부, 학습·검증 기준월, 기준월 컷오프 확정.

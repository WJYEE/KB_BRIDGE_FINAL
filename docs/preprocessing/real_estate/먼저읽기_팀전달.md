# 먼저읽기 — 부동산 전처리 팀 전달본

**현재 기준의 전처리 전달본이다. 모델 채택 여부와 성능 검증은 별도 작업이다.**

## 사용할 파일
- 주 사용 CSV는 **`부동산_행정동별_월별_연결자료.csv` 하나**다(1,632행 × 26열, UTF-8 BOM).
- 열 설명은 `변수정의서.md`, 처리 방법은 `처리기준서.md`, 검수 결과는 `검수표.csv`에 있다.

## 한 행의 의미
**행정동 × 기준월** 한 칸이다. 그 행정동과 겹치는 한국부동산원 조사상권의 임대료·공실률을 면적가중으로 연결한 **조사상권 기반 대리변수**이며, 행정동 전체의 공식 통계가 아니다.

## 연결 방법
- 연결 키는 **`행정동코드_카드10자리` + `기준월`**(YYYY-MM)이다.
- **전체 점포의 월별 학습표를 기준으로 10자리 행정동코드+기준월로 LEFT JOIN한다.** 부동산 자료가 없는 점포도 그대로 유지한다.
- **INNER JOIN이나 결측 행 일괄 삭제를 하지 않는다. 빈값을 0으로 바꾸지 않는다.** 빈값은 ‘자료 없음·연결 보류·공표 전’ 중 하나이며 0%와 다르다. 실제 0 값은 그대로 들어 있다.
- 코드와 기준월은 **문자열로 읽는다.** 예: `pd.read_csv(..., encoding="utf-8-sig", dtype={"행_키": str, "기준월": str, "행정동코드_SGIS": str, "행정동코드_카드10자리": str})`
- 행정동코드, 지역명(`시군구명`, `행정동명`), `행_키`는 **연결·확인용이므로 모델 입력으로 넣지 않는다.** 모델 후보는 지표 6개와, 필요하면 커버율·유효상권수 열이다.

## 범위
| 항목 | 내용 |
|---|---|
| 기준월 | 2024-11 ~ 2026-10 (24개월) |
| 지역 | 부산 206개 행정동 중 조사상권과 겹치는 **68개 동**(소규모 61, 집합 41, 일반·1층 61) |
| 소규모·집합 공실률, 소규모·집합 임대료 | 2024-11 ~ 2026-10 |
| 일반 상가 공실률, 일반 상가 1층 공실률 | 2026-05 ~ 2026-10 (그 전 달은 빈값) |
- 이 파일에 없는 행정동·기준월은 부동산 값이 없는 칸이다. LEFT JOIN 후 빈값으로 남는다.
- 2024-10 이전은 원본 값이 있어도 **과거 경계 연결 보류**로 연결하지 않았다.

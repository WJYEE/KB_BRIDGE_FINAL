# 기본 전처리 v10: 폐업일 없는 폐업 기록 제외

## 최신 팀 결정
영업상태명=폐업이고 폐업일자=빈값이면 기본 정제본에서 제외합니다. 날짜는 임의로 채우지 않았습니다.
기간 필터 이후 전체 48,222건에서 해당 조건은 2,909건입니다. 이 중 기존 포함 1,325건과 기존 주소보류 1건을 새로 제외했고, 나머지 1,583건은 이미 다른 사유로 제외돼 있었습니다. 중복 제외로 집계하지 않았습니다.
현재 폐업이라는 원본 상태는 보존하되 해당 기록은 분석용 파일에 넣지 않습니다. 전체 보존본·별도 제외기록표에는 사유와 함께 남겼습니다.

## 보존한 기존 기준
- 카드업종은 기존 팀표+사용자가 채택한 추정 매핑 적용. 소독업·저수조청소업·승강기유지관리업체의 생활 매핑 유지.
- 카드 분류가 어려운 업종은 분석 제외. 공식 코드 사전과 확인된 분류가 아닌 추정 연결은 카드매핑상태·근거로 구분.
- 영업/정상만 현재정상영업여부=T. 그 외 F이며 F를 12개월 폐업 라벨 1로 쓰지 않습니다.
- 인허가일 결측 10건과 정상 상태이면서 폐업일 존재 4건도 정제본에서 행 자체를 제외했습니다. 이번추가제외_14건.csv에서 기록을 확인할 수 있습니다. 나머지도 패널·라벨 생성 전 학습 적합성 확정은 아닙니다.
- 좌표 누락은 삭제하지 않고 추후 주소·행정동 연결 때 보완합니다.
- 원본 소재지면적과 소재지면적_분석용은 유지. 원본 0·빈값은 분석용에서 빈값, 양수 유지. 면적을 학습 입력에서 제외하려면 향후 학습 코드에서 적용해야 합니다.
- 완전 동일행·인허가 복합키·ID 중복은 없었고 확정 중복 삭제는 0건입니다. 동일 가게의 복수 인허가 후보는 자동 병합하지 않았습니다.
- 날짜·좌표·주소·면적 원천 값과 카드 분류를 이번 단계에서 새로 변경하지 않았습니다. 변경한 것은 폐업일 결측 기록의 분석 포함 및 학습 사전 판정입니다.

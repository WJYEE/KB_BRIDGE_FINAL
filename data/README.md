# 데이터 보관 안내

원본·점포별 정제본·통합 Parquet는 이 업로드 묶음에 포함하지 않았습니다.
팀 구글드라이브의 권한 있는 작업 폴더에서 별도로 준비합니다. 공개 공유 링크는 기재하지 않습니다.

- 최근 전체 모델링용 파일명: `모델직전_통합데이터_모델링용_ver2.parquet`
- 최근 사용자 실행 결과: 5,412,656행 × 143열. 이번 정리 작업에서 대용량 파일을 다시 열어 검증한 것은 아닙니다.
- 인구·방문·관광 통합 변수: 예측기준월×행정동. 구군 자료는 해당 구군의 동에 같은 값으로 연결됩니다.
- 인구·방문·관광은 전월 관측자료를 연결하는 소급평가 기준이며 실제 공개지연은 반영하지 않았습니다.
- 부동산은 조사상권 표본의 행정동 연결 대리변수입니다. 행정동 전체의 실제 공실률·임대료가 아닙니다.

개별 노트북의 입력 파일명·경로는 원래 코드에 남겨 두었습니다. 현재 폴더에 자동 연결되는 전체 파이프라인은 아직 없습니다.
입수 조건이 다른 데이터는 해당 조건을 확인한 뒤 사용합니다.

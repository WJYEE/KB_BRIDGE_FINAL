# AI 기반 부산 상권 위험 조기진단 및 정책지원 의사결정 보조 대시보드

KB Bridge 파이널 프로젝트 · 상권전략분석 6팀

부산 점포의 향후 **6개월 내 폐업위험**을 예측하고 행정동·업종별로 집계해, 담당자가 우선 확인할 지역과 주요 예측 요인을 살펴보도록 돕는 프로젝트입니다.
핵심 사용자는 부산신용보증재단 보증사업 기획·리스크 관리 담당자를 가정합니다.

## 현재 진행 상태

2026-10-30 기준으로 제공받은 전처리·파생변수·EDA 코드와 문서를 정리했습니다.
카드·통신 EDA, 통신 4개 지표 재계산 검산, 카드·통신 병합 코드도 확보했습니다. 전체 자료의 최종 병합 코드, 카드 주요 지표 생성·저장 및 통신 원본 정제·최종 저장 코드, 최종 모델·대시보드 코드는 추가 반영 예정입니다.
**모든 코드를 한 번에 실행하는 완성 파이프라인이나 배포 완료본은 아닙니다.**

## 목표 기능

- 행정동별 평균 폐업확률·예상 폐업점포 수의 지도와 순위.
- 행정동 안의 업종별 위험 비교.
- SHAP 기반 예측 영향 요인과 자료 결측·관측기간 안내.
- 검증된 수치와 그래프를 담은 리포트 제공.

위 항목은 PRD의 목표입니다. 구현 완료 여부는 실제 앱·모델 코드가 추가된 뒤 별도로 기록합니다.

## 실행 방법

1. 팀의 권한 있는 데이터 보관 위치에서 해당 노트북이 요구하는 입력 파일을 준비합니다.
2. Python 환경에 주요 패키지를 설치합니다: `python -m pip install -r requirements.txt`.
3. Colab 노트북은 Colab에서 열고 Google Drive를 연결합니다. 코드에 적힌 원래 경로를 본인의 데이터 경로로 맞춥니다.
4. 노트북의 설명과 처리 기준을 확인한 뒤 필요한 단계만 실행합니다. 인허가 노트북 전체 실행 순서는 담당자 확인 전입니다.
5. 부동산 코드는 입력 경로와 이전 단계 의존성이 있어 해당 단계 문서를 먼저 확인합니다.

API 수집을 실행할 때만 본인의 인증키를 외부 환경에 설정합니다. 키를 코드·노트북 출력·커밋에 적지 않습니다.
test_data.ipynb는 `DATA_GO_KR_SERVICE_KEY`, 초기 extract.ipynb는 `DATA_GO_KR_API_KEY`를 사용합니다.
패키지 버전 고정과 전체 데이터 재실행은 이번 파일 정리 작업의 검증 범위에 포함되지 않습니다.

## 분석 결과와 해석

최근 전체 설명변수 Pearson 상관분석 결과는 reports/correlation에 있습니다.
사용자 실행 결과 기준 학습 범위는 2023-01~2025-02, 3,299,434행이며 수치 설명변수 41개를 비교했습니다.
외국인·외지인 각각의 전월 변화율과 직전 3개월 평균 대비 변화율에서 절댓값 0.8 초과 쌍이 확인됐습니다.
상관이 높다는 이유만으로 변수를 자동 삭제하지 않으며 채택은 검증 성능과 해석을 함께 비교합니다.

인구·방문·관광은 전월 자료를 사용한 소급평가입니다. 실제 공개지연을 반영한 실시간 재현 성능으로 해석하지 않습니다.
부동산 값은 조사상권 표본에서 연결한 참고값이며 행정동 전체의 실제 통계가 아닙니다.

## 이용 범위

결과는 지역 분석 참고정보입니다. 개별 보증 승인·거절, 신용평가, 예산·보증 재원 배분 결정에 사용하는 도구로 제공하지 않습니다.
폐업위험과 보증사고 위험은 다르며 SHAP 요인은 폐업 원인의 인과 증거가 아닙니다.
